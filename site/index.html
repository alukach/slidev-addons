Slidev Addons

Addons for Slidev. Each demo below is a deck built with that addon. Source: alukach/slidev-addons.

  • Tier list · @alukach/slidev-addon-tierlistDrag-and-drop S–F tier list that links to detail slides with tier badges.
  • Live demo · @alukach/slidev-addon-live-demoEmbed live web apps, with zoom, crop, video fallback and multi-demo reels.
  • Hotkeys · @alukach/slidev-addon-hotkeysGive any slide a key that jumps to it.
  • Laser pointer · @alukach/slidev-addon-laserA fading laser trail, mirrored between presenter and audience.
